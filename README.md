# نبض الشبكة

اختبار سرعة وجودة الإنترنت يعمل من متصفح الآيفون مباشرة، ويُثبَّت على الشاشة الرئيسية كتطبيق (PWA).

- يقيس فعلياً: التحميل، الرفع، زمن الاستجابة، Jitter، و Bufferbloat أثناء التحميل والرفع، وثبات السرعة.
- القياس عبر خوادم Cloudflare العامة (`speed.cloudflare.com`).
- السجل محفوظ على الجهاز فقط (localStorage).
- لا يعرض أرقاماً لا يمكن قياسها من المتصفح (فقد الحزم، إشارة Wi‑Fi، DNS).

الخط: Noto Sans Arabic (SIL OFL 1.1) — انظر `fonts/OFL.txt`.

## الإصدار 2.0
- اختبار تكيّفي: يبدأ بطلبات 100KB واتصالات قليلة ويكبّرها حسب السرعة (حتى 8 اتصالات)، مع وضع «اقتصادي» افتراضي يتوقف عند استقرار السرعة وبسقف للبيانات.
- شاشة الشبكة: خادم القياس، IP العام (مخفي افتراضياً)، فحص توفر IPv4 و IPv6، HTTP/TLS، ومراقب استجابة لمدة 60 ثانية.
- السجل: مقارنة بالاختبار السابق وحذف نتيجة مفردة.
- وضع داكن يتبع النظام.
